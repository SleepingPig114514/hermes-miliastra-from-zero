## P0 立项
1. 追问：一次一个问题、萌新白话（方法论=release/01；对用户说话=24 号任务书）。
2. **画面期望轻问（2 问，白话；话术禁出现 R1/R2/图元/模板/素材编号）**：① 有没有画面参考（一张图 / 某游戏截图 / 一句感觉）② 这游戏里你最在意"像"的是什么。机制=《工具书》§十「资产需求判定与提问」。
3. **预期管理必说**（原文=流程规范 v2 P0 行）：美术只能组合官方图元/模板，不能导入自定义 PNG。**路线选定是 AI 侧动作**——立项不要求玩家做美术规划，别把路线清单摆给玩家选。
4. 五件套初始化：`mkdir -p projects/<名>/demo projects/<名>/lua_out`；各文件职责=根 AGENTS §10 表。
5. 立项卡填完 → 用户批准 = 出门门禁。
