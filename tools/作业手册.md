## 一、跨会话交接协议（多会话接力）

- **接力棒 = 项目状态文件**：任何会话收尾前，把"当前阶段 / 下一步第一条可直接执行的命令 / 等用户做什么"三样写进去。下一会话凭这三样冷启动，不读聊天历史。
- **会话开工只读两样**：状态文件 + 当前阶段分册；其他文档按需再查，禁止全量通读（上下文成本纪律）。
- 门禁未过不得把"下一步"写进新阶段；状态文件与分册冲突，以状态文件实况为准（它记录做到哪，分册只说该怎么做）。

## 五、本手册自有实测坑（2026-10-10）

1. **deploy_lua 多映射**：`Beyond_Local_Save_Level/` 下可多个映射并存（1826 有内容 / 1827 空新建），mtime 最新≠正确。脚本已改为"含同名脚本的目录优先"，仍歧义时 `--list` 看候选、`--map-dir` 显式指定。
2. **studio replace 复现包**：authoring JSON 的 `meta.giaOwnerUid/giaFileId/giaFileName` 决定导出文件名与归属，照抄探针样本改这三项即可。
3. **闸门与批准**：跨轮写文档必过 write-gate 卡；多文件改动并进一张卡（根 AGENTS §11-4）。
