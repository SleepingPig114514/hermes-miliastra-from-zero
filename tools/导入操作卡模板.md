> **【AI 前置准备】三项做完才发卡**（用户拿到卡即可一路走完，中途不必再找 AI）：

> ② **投递脚本**：`python tools/deploy_lua.py projects/<项目>/levelScript.lua`（自动跑沙箱门禁 → 自动发现 `<UID>/…/<地图ID>/external_lua_file/` → 复制 → sha256 回读）；
> ③ **确认坐标**：`python tools/gil_id_extract.py --latest` / `deploy_lua.py --list` 自动发现并打印 **UID / 地图ID / 存档大小 / 保存时间 / 脚本名**；**但要把【UID + 地图ID】报给用户核对一句**（见下「★ UID 与存档 ID 怎么确认」）。
> 详细度标准：**每一步都要写清"在哪里、点什么按钮"**，不写用途解释、不写配置项（配置由代码负责）。
> **★ 出卡自检（硬性，2026-10-11 加）★**：发卡前逐项过一遍——① **不得残留 `<…>` 占位符**（UID / 地图ID / 包文件名 / 模板名 / 清单都要填实）；
> ② 不得残留 `⏳ 待执行`；第 0 节三项必须写成 `✅ 已完成（含实测值：sha256 / 目标身份）`；
> ③ **必须保留"前提：全程在千星沙箱编辑器内操作"那段**（实测用户会卡在"要不要回到游戏里"，第 4 步的菜单只有编辑器有）。

### ★ UID 与存档 ID 怎么确认（多账号 / 多存档防错，2026-10-10 加）

存档路径 = `…\BeyondLocal\<UID>\Beyond_Local_Save_Level\<地图ID>\<地图ID>.gil`，**两层编号都可能认错**：

| 项 | 用户能否自己看到 | 怎么看 / 怎么办 |
|---|---|---|
| **UID**（玩家号） | ✅ **能** | 游戏内**试玩画面右下角水印**就有：`奇域试玩中… UID: <你的UID>`；或「个人信息」页。AI 报出 UID → 用户对照水印一秒确认 |
| **地图ID**（存档号） | ❌ **看不到** | 编辑器界面**不显示**这个数字，它就是文件夹名。**禁止反问用户"你的地图ID是多少"**（无效问法）——正确做法：AI 列候选表（带指纹）让用户认 |

⚠️ **本机实测的坑（2026-10-10）**：一个 `BeyondLocal\` 下有 **16 个 UID 目录**（其中 15 个是游戏缓存的其他玩家空壳），同一 UID 下还会**并存多张图**。工具自动发现按「含同名脚本 → mtime 最新」选，**不保证是你要的那张**（空图的目录 mtime 可能更晚）。

```bash
python tools/deploy_lua.py <脚本> --list    # 列全部候选 + 指纹（UID / 地图ID / 存档大小 / 保存时间 / 脚本）
python tools/gil_id_extract.py --latest     # 打印选中身份 + 其他候选
```

**AI 纪律**：把选中的 `UID + 地图ID + 保存时间 + 存档大小` 报给用户，得到"就是这张"再动手；用户说不对 → 用 `--uid` / `--map-dir` 显式指定，或按保存时间/大小让用户指认。

## 你要做的（约 10 分钟）

> **⚠️ 前提：本卡全程在【千星沙箱编辑器】里操作。**
> 路径＝游戏（原神）→ **千星沙箱** → 打开目标关卡 → 进入**编辑器**界面。
> 下文第 2 步的「界面控件组管理」、第 4 步的「窗口 → 客户端脚本资源管理器」**都是编辑器里的菜单**；
> 游戏内的**试玩界面没有这些菜单**，不需要回到游戏里。菜单找不到 → 直接截图发 AI（版本间菜单位置会差）。

### 一、导入资产包

1. **包与脚本均 AI 已放好**——你不用复制任何文件，直接往下做。
2. **进编辑器**：原神 → 千星沙箱 → 打开目标关卡（地图 `<地图ID>`）
3. **打开导入窗口**：点界面**左上角的「资产导入导出」按钮**（不是顶部「窗口」菜单——菜单里可能没有这一项）
4. **入库**：在窗口里点 **「加载外部资产」** → 在列表里**勾选 `<包文件名>`** → 点 **「转移选中资产」**
5. **二次确认弹窗**：弹出标题为**「转存资产」**的窗口 → 单选**「导入资产」**（⚠️ 不要选「默认页签」）→ 点 **「确认」**
   （弹窗会提示"将清空当前存档的可撤销/还原操作"——正常，继续）
6. **保存关卡**：关掉窗口回到编辑界面，按 **Ctrl+S**（⚠️ 存**关卡本体**；只存节点图窗口不算——AI 要从这份存档读新索引）

### 二、建客户端控件容器（关卡重建后需重做）

7. 顶部菜单点 **「界面控件组管理」** → 切到 **「界面布局」** 页签 → 左下角点 **「添加界面控件」** → 展开 **「预制模板」** → 选 **「客户端控件容器」** 创建
8. **选中**刚建的容器 → 右侧面板 **「画布设置」** → 点 **「前往编辑」**，进入容器详情界面
9. 在容器详情里确认选中了 **「容器节点」** 即可（**不用复制**——容器节点索引由 AI 从关卡存档自动读取）

### 三、建两个客户端控件模板（已存在则跳过）

10. 顶部菜单点 **「界面控件组管理」** → 切到 **「界面控件组库」** 页签 → 再切到 **「客户端控件模板」** 子页签 → 点**左下角「添加客户端控件」**（注意不是"添加界面控件"）
11. 在控件类型列表里选 **「文本框」** → 确认/保存（**不用复制索引**——AI 会从存档自动读取）
12. 重复第 10–11 步，这次选 **「光标检测区域」**
    （**只建空模板**：不用设文字/颜色/尺寸/位置/锚点，也**不用拖进容器画布**——脚本运行时自动创建）

### 四、建脚本映射并挂到容器

13. **脚本文件 AI 已放好**（`…\BeyondLocal\<UID>\Beyond_Local_Save_Level\<地图ID>\external_lua_file\levelScript.lua`）。
    > 该位置由 `tools/deploy_lua.py` 投递并做 sha256 回读校验，你不用复制；以后 AI 每次改完脚本都会刷新它。
    > 若编辑器选不到该文件，把它移到同目录下的 `default_import_file\` 子文件夹再试（真机日志里的脚本路径是 `default_import_file/levelScript`）。
14. 顶部菜单点 **「窗口」** → **「客户端脚本资源管理器」** → 左侧**双击「未分类页签」**（或你自己建的文件夹）进入该文件夹
15. 在该文件夹内**空白处右键** → 选 **「新建脚本映射」**（⚠️ 别选「新建客户端脚本」——那个是创建式，会撞同名建出重复文件）
16. **选中**刚建的映射 → 点 **「编辑脚本映射路径」** → 在打开的选文件窗口里，**把下面这行整行粘贴进"文件名"框并回车**（比一层层翻目录稳）：
    `%USERPROFILE%\AppData\LocalLow\miHoYo\原神\BeyondLocal\<UID>\Beyond_Local_Save_Level\<地图ID>\external_lua_file\levelScript.lua`
    （**关键步骤**：只有建立了映射的 lua 才会被上传，光有本地文件不生效；关联成功会在映射旁显示文件名）
17. 回 **「界面控件组管理」→「界面布局」** → **选中容器** → 右侧「画布设置」→「前往编辑」→ 右侧切到 **「脚本」页签** → 点 **「添加脚本」** → 选第 15 步建的那个映射
18. 按 **Ctrl+S 保存关卡**

### 五、回报（发给 AI）

1. 聊天里说一句"**导入完成**"。
2. **不用抄任何索引**：AI 用 `python tools/gil_id_extract.py --latest` 直读关卡存档，自动回收全部「模板名 → 真机ID」。
3. **首轮抽查（只做一次）**：编辑器里点模板 **`<清单第一个模板名>`** → 检视器「控件模板索引」→ 发 AI（校准自动读取结果；对一次即永久销账，以后不用再做）

## 注意事项

- 本次导入的模板：`<模板名1>`、`<模板名2>`、…（共 `<N>` 个）
- 出现重名或 `_1` 后缀 = 旧版本还在，**别导入，先告诉 AI**：`<旧模板名列表>`
- **不要改模板名**——名字是 AI 识别每个资产的唯一主键
- 导入后到试玩前若报"缺项 / 停在标题"，是索引还没回填，等 AI 跑完读取和部署（几分钟），**不用重试导入**

- 找不到某个按钮 → 直接截图发 AI，AI 按你的实际界面报菜名（版本间菜单位置会差）
